Elsaka Leave Rule Features



Companies needs always system allow them to define rules for leaves,



Elsaka Leave Rule module will help you to define many rules by just simple configuration,



here are some examples which can be handled by that module:-

1- Minimum, 15, Minuets per request

2- Minimum , 1, day, per request,

3- Maximum 2 hours per request,

4- Maximum 2 days per request,

5- Total 4 Requests per month

6- Total 8 Hours per month,



According to the configuration system will not accept any leave not meeting defined rules
